Catatan Keuangan PWA & AI

Aplikasi Web Progresif Manajemen Finansial Pribadi: 100% Offline-First, Kedaulatan Data Lokal Penuh, Dual-Engine AI, dan 23 Koleksi Gaya Tema Visual.

Pengembang: Personal Notes Project Arsitektur: SPA Vanilla JS (Zero-Dependency) Skema Data: v4 (Enterprise PWA) Verifikasi: 14/14 Automated Test Suite Lolos (DOM, Storage, PWA) Rilis: November 2026
1 4 Pilar Arsitektur Offline-First PWA

Catatan Keuangan dirancang untuk menjamin privasi absolut bagi pengguna tanpa keharusan membuat akun di server eksternal, bebas iklan komersial, dan sepenuhnya beroperasi di perangkat lokal berdasarkan 4 pilar arsitektur:

🔒 Kedaulatan Data

Bebas akun server & tanpa tracking. Data tersimpan 100% di browser pengguna melalui IndexedDB & LocalStorage privat.

⚡ Offline-First Sejati

Didukung Service Worker & Cache Storage API. Dapat diinstal di Android/iOS/PC dan berfungsi penuh tanpa kuota/internet.

🚀 Performa Ringan

Dibangun tanpa framework berat (Zero Heavy Bundles). Aset statis lokal dicache seketika untuk pemuatan instan.

☁️ Backup Mandiri

Sinkronisasi otomatis ke Google Drive pribadi pengguna melalui OAuth 2.0 PKCE tanpa perantara server backend.

2 Spesifikasi Teknis & Lingkungan Eksekusi Peramban

Aplikasi ini mengintegrasikan seluruh instrumen keuangan pribadi sehari-hari dalam satu layar terpadu tanpa ketergantungan runtime luar:

Komponen Sistem Teknologi & Standar Web Perilaku Penyimpanan & Runtime
Database Transaksi IndexedDB (Store: transaksi, dompet, wishlist, berulang) Persistensi lokal terproteksi via navigator.storage.persist() agar tidak dihapus otomatis saat memori minim.
PWA Service Worker Cache Storage API (Strategi Cache-First dengan fallback aman) Aset HTML, CSS, font, dan JavaScript disimpan lokal untuk akses instan seketika dalam kondisi offline.
Dual-Engine AI Local Regex/NLP Parser + Dynamic Google Gemini REST API Mode offline 100% lokal; mode online via API Key pribadi pengguna (BYOK) dengan hanya data agregat yang dikirim.
Cloud Sync & Backup Google Drive REST API via Standar OAuth 2.0 PKCE Koneksi langsung dari peramban ke akun Google Drive pribadi pengguna dengan format JSON terstruktur skema v4.
Zero Tracking & Zero Ads: Bebas skrip analitik pelacak, tanpa cookie pihak ketiga, dan tanpa iklan pihak ketiga. Seluruh pembukuan keuangan adalah milik pribadi pengguna sepenuhnya.

3 7 Modul Fitur Finansial Utama
Modul Fitur Fungsi & Kapabilitas Sistem Keunggulan Khusus
Smart Input & Voice (Mikrofon) Pencatatan ekspres berbasis teks bebas atau pengenalan suara (Web Speech API). Parser NLP lokal otomatis mendeteksi nominal angka (25k, 50rb, 1.5jt), kategori pengeluaran, tanggal, dan metode bayar. Pemrosesan instan di peramban tanpa jeda server. Terdapat tombol mikrofon untuk input suara hands-free.
Multi-Dompet & Rekening Pemisahan saldo antara Kas Tunai Fisik, Rekening Bank (BCA, Mandiri, BRI, BNI, Jago, SeaBank, dll.), dan E-Wallet (DANA, GoPay, OVO, ShopeePay, LinkAja). Kalkulator stok lembaran fisik uang kertas (Rp 1.000 s/d Rp 100.000) dan mutasi transfer antar dompet dengan biaya admin. Mendukung opsi saldo minus untuk PayLater/Kartu Kredit.
Target Tabungan (Wishlist) Perencanaan impian atau dana darurat (laptop, liburan, investasi). Menghitung nominal target, akumulasi setoran terkumpul, kekurangan dana, persentase progres, dan sisa hari tenggat. Rekomendasi setoran mingguan otomatis agar target dapat tercapai tepat waktu sebelum tanggal tenggat.
Transaksi Berulang (Recurring) Jadwal otomatis transaksi rutin (sewa kos, tagihan WiFi, cicilan, langganan aplikasi digital, maupun pemasukan gaji rutin) secara mingguan atau bulanan. Kalkulasi total estimasi beban pengeluaran rutin bulanan vs pemasukan rutin serta logika catch-up otomatis untuk jadwal yang terlewat.
Batas Anggaran (Budget) Penetapan batas pengeluaran per kategori secara fleksibel (mingguan atau bulanan) dengan pengawasan kuota sisa limit secara real-time. Tiga indikator visual: 🟢 Aman (<80%), 🟡 Waspada (≥80%), dan 🔴 Overbudget (≥100%).
Keranjang & OCR Scan Struk Pencatatan nota belanja terperinci multi-item lengkap dengan kuantitas, harga satuan, dan diskon. Mendukung lampiran foto struk fisik dan scanner OCR. Perhitungan subtotal akurat, memudahkan verifikasi belanjaan pasar atau supermarket tanpa selisih sepeser pun.
Laporan & Grafik Dwi-Seri Visualisasi arus kas dwi-seri (saldo tunai vs saldo e-wallet/bank), diagram lingkaran distribusi pengeluaran, serta analisis tren 30 hari terakhir. Filter rentang tanggal kustom dan ekspor data ke format CSV laporan untuk Excel/Spreadsheet.
Penyimpanan Persisten Otomatis: Aplikasi memanggil API modern navigator.storage.persist() saat inisialisasi awal untuk meminta perlindungan penyimpanan dari browser, mencegah data riwayat terhapus saat memori perangkat penuh.

4 Diagram Alur Kerja (User Flow & Workflow) Fitur Finansial Inti

Setiap modul finansial dioperasikan melalui alur kerja deterministik yang menjamin akurasi mutasi saldo, validasi kuota batas anggaran, serta sinkronisasi visual secara seketika (real-time).

📝 Flow 1: Siklus Pencatatan Transaksi Cepat & Smart Voice
Pencatatan Transaksi
01 INPUT PENGGUNA
Ketik teks santai ("Kopi 25k BCA"), tekan tombol mikrofon suara, atau buka form manual / mode keranjang belanja multi-item.
➔
02 PARSER NLP LOKAL
Algoritma teks mengekstrak tipe (Pengeluaran/Pemasukan), nominal angka (k/rb/jt), kategori belanja, dompet sumber, dan tanggal transaksi.
➔
03 VALIDASI SALDO
Sistem memverifikasi saldo dompet (kecuali dompet yang diizinkan bersaldo minus seperti PayLater) dan format input.
➔
04 EKSEKUSI & REFRESH
Catatan disimpan ke IndexedDB, saldo dompet termutasi seketika, kuota batas anggaran terpotong, grafik arus kas terupdate.
💼 Flow 2: Manajemen Multi-Dompet, Kas Fisik & Mutasi Transfer
Saldo & Rekening
01 SETUP DOMPET
Tambahkan akun rekening Bank (BCA/Mandiri/Jago), E-Wallet (DANA/GoPay), atau Kas Fisik. Tersedia opsi izin saldo minus (PayLater).
➔
02 OPNAME FISIK KAS
Pengguna mengisi jumlah fisik lembaran uang kertas (Rp 1k s/d 100k) pada kalkulator fisik untuk mencocokkan uang di dompet riil.
➔
03 FORM TRANSFER
Pilih akun asal, akun tujuan, nominal transfer, serta biaya administrasi transfer antar-bank jika diberlakukan.
➔
04 MUTASI GANDA
Saldo asal berkurang (nominal + biaya), saldo tujuan bertambah (nominal), riwayat transfer tercatat rapi.
🎯 Flow 3: Pemantauan Batas Anggaran & Ambang Batas Otomatis
Batas Anggaran
01 PENETAPAN LIMIT
Pilih kategori pengeluaran (misal: Makanan) dan tentukan kuota batas nominal (misal: Rp 1.500.000 / bulan).
➔
02 TRACKING OTOMATIS
Setiap transaksi pengeluaran baru pada kategori tersebut secara otomatis diakumulasikan ke total pemakaian periode.
➔
03 AMBANG BATAS SISTEM
Sistem mengevaluasi rasio: 🟢 Aman (<80%), 🟡 Waspada (80-99%), atau 🔴 Overbudget (≥100%).
➔
04 PERINGATAN & TIPS AI
Progress bar berubah warna real-time dan asisten AI langsung memberikan peringatan serta saran penghematan taktis.
🏆 Flow 4: Perencanaan Target Tabungan & Rekomendasi Setoran
Target Impian
01 BUAT TARGET
Masukkan nama impian (misal: Laptop Kerja), nominal target (Rp 15.000.000), dan batas tanggal tenggat (deadline).
➔
02 SETORAN BERTAHAP
Pengguna menyisihkan tabungan berkala melalui tombol Setor dari saldo rekening aktif yang dimiliki.
➔
03 KALKULASI MINGGUAN
Sistem menghitung persentase progres, sisa hari, dan otomatis merekomendasikan: sisa_dana / sisa_minggu.
➔
04 TARGET TERCAPAI
Ketika dana 100% terkumpul, status berubah menjadi Tercapai 🎉 dan dana impian siap dialokasikan untuk belanja.
🔄 Flow 5: Otomasi Tagihan Rutin & Transaksi Berulang
Jadwal Rutin
01 DAFTARKAN TAGIHAN
Daftarkan tagihan rutin (WiFi Rp 350k, Kos Rp 1.2jt, Spotify Rp 55k) atau pemasukan berkala (Gaji Bulanan).
➔
02 ATUR SIKLUS WAKTU
Tentukan interval perulangan (Harian, Mingguan, Bulanan, Tahunan) dan tanggal jatuh tempo pembayaran berikutnya.
➔
03 DETEKSI JATUH TEMPO
Saat aplikasi dibuka, mesin memeriksa tanggal sistem terhadap jadwal jatuh tempo serta mendeteksi jadwal yang terlewat.
➔
04 PROYEKSI & KOMITMEN
Transaksi tercatat ke riwayat pembukuan dan total komitmen rutin bulanan tersaji transparan di analitik AI.
Keandalan Logika Finansial & Catch-Up Jadwal: Seluruh mutasi dwi-entri dieksekusi secara atomik di IndexedDB. Transaksi berulang mengimplementasikan logika catch-up otomatis: jika aplikasi tidak dibuka selama beberapa hari melewati tanggal jatuh tempo, sistem mendeteksi selisih hari dan memunculkan transaksi yang terlewat untuk dicatat secara utuh tanpa ada tagihan yang hilang.

5 Diagram Alur Kerja Asisten AI, Cloud Sync & Personalisasi

Alur kerja kecerdasan buatan, sinkronisasi cloud mandiri tanpa server, pencadangan database, dan pergantian gaya antarmuka visual dinamis.

✨ Flow 6: Asisten AI Finansial (Q&A Data & Draf CRUD Transaksi)
Dual-Engine AI
01 TAP TOMBOL TANYA AI
Tekan FAB ✨ Tanya AI di sudut kanan bawah. Bottom sheet interaktif terbuka dengan tombol saran pertanyaan cepat.
➔
02 ROUTING DUAL-ENGINE
Jika offline: Mesin NLP Lokal menjawab saldo, anggaran & target. Jika online & punya API Key: Google Gemini merespons cerdas.
➔
03 GENERATE KARTU DRAF
Jika pesan berupa pencatatan (misal: "Beli bensin 50k DANA"), AI membuat kartu [📝 Draf Transaksi AI] di obrolan.
➔
04 KONFIRMASI PENGGUNA
Pengguna cukup klik [➕ Simpan] untuk eksekusi langsung, [✏️ Form] untuk revisi detail, atau tombol Batal.
☁️ Flow 7: Sinkronisasi Google Drive Mandiri (OAuth 2.0 PKCE)
Cloud Sync
01 INISIASI LOGIN
Buka menu Setelan, klik tombol Hubungkan Google Drive untuk memulai proses otentikasi akun Google pribadi.
➔
02 PKCE CODE CHALLENGE
Peramban mengarahkan ke consent screen Google dengan verifikasi kriptografis SHA-256 PKCE tanpa Client Secret backend.
➔
03 ACCESS TOKEN PRIVAT
Token akses privat diterima langsung di peramban dan disimpan lokal untuk berkomunikasi langsung ke REST API Google Drive.
➔
04 SINKRONISASI DATA
Snapshot database diunggah/diunduh langsung melalui HTTPS ke folder pribadi Google Drive pengguna tanpa melalui server perantara.
💾 Flow 8: Siklus Ekspor, Impor & Pemulihan Cadangan Data (JSON/CSV)
Backup & Restore
01 PILIH MODE EKSPOR
Klik Export backup, lalu pilih: JSON Standar atau Terenkripsi Kata Sandi (AES-GCM 256-bit).
➔
02 ENKRIPSI & UNDUH
Jika diproteksi, kunci diturunkan via PBKDF2 (100k iterasi). Berkas cadangan terenkripsi aman langsung terunduh.
➔
03 UNGGAH CADANGAN
Pada perangkat lain, pilih berkas JSON cadangan. Sistem otomatis mendeteksi apakah berkas terenkripsi atau polos.
➔
04 DEKRIPSI & RESTORE
Masukkan kata sandi pengunci untuk mendekripsi data. Setelah valid, seluruh saldo dan riwayat transaksi dipulihkan.
🎨 Flow 9: Personalisasi Antarmuka & Pergantian 23 Gaya Tema Visual
Personalisasi Tema
01 BUKA GALERI TEMA
Pengguna menuju tab Setelan dan menjelajahi kartu katalog pratinjau 23 gaya tema artistik yang tersedia.
➔
02 PILIH PRESET GAYA
Ketuk gaya yang diminati (misal: Midnight Gold, Matcha Zen, Neobrutal, Retro, atau Spider).
➔
03 INJEKSI CSS INSTAN
Sistem menyuntikkan variabel warna CSS, radius sudut, gaya font, dan efek Liquid Glass navbar secara instan tanpa reload.
➔
04 PERSISTENSI STORAGE
ID tema disimpan di LocalStorage sehingga aplikasi selalu tampil sesuai tema pilihan pengguna setiap kali dibuka.

7 Arsitektur Asisten AI Finansial: Dual-Engine & Interaksi Chat

Aplikasi menyematkan tombol melayang ✨ Tanya AI (FAB) pada sudut kanan bawah dengan jarak pemisah ergonomis (~22px) di atas bilah navigasi. Dialog AI hadir dalam bentuk Bottom Sheet responsif yang dapat dioperasikan mudah dengan satu tangan pada ponsel cerdas.

🌱 Mesin Lokal (100% Offline & Privat)

Beroperasi seketika di CPU peramban tanpa koneksi internet atau API key. Memproses:

  • Saldo & Dompet: Analisis saldo total, kas fisik, dan rincian e-wallet (DANA, GoPay, dll.).
  • Arus Kas 30 Hari: Pemasukan, pengeluaran, surplus/defisit, dan kategori paling boros.
  • Target Tabungan: Progres terkumpul, kekurangan, sisa hari, dan setoran mingguan.
  • Transaksi Berulang: Daftar tagihan rutin dan estimasi komitmen bulanan.
  • Batas Anggaran: Peringatan dini overbudget pada kategori yang ditetapkan.
  • Aksi CRUD Percakapan: Pembuatan kartu draf transaksi, form edit draf, dan konfirmasi hapus transaksi langsung dari ruang obrolan.
✨ Google Gemini API (Dynamic Discovery & Free Tier)

Diaktifkan saat pengguna memasukkan API Key Google Gemini pribadi (BYOK):

  • Deteksi Model Dinamis: Aplikasi mendeteksi model yang aktif secara otomatis via endpoint REST API v1beta/models Google AI Studio.
  • Prioritas Flash-Lite Bebas Kuota: Mengutamakan varian Flash-Lite efisien (seperti gemini-2.5-flash, gemini-2.0-flash, atau generasi penerus Flash-Lite yang tersedia di akun pengguna).
  • Simulasi Keuangan Cerdas: Menganalisis ketahanan uang (misal: "Dikasih uang 500rb bertahan berapa hari?" dihitung berdasarkan laju pengeluaran harian).
  • Rekomendasi Berhemat: Memberikan saran penghematan taktis pada kategori belanja tertinggi.
  • Format JSON Otomatis: Menghasilkan blok transaksi terstruktur yang langsung dikonversi menjadi kartu draf interaktif di obrolan.
  • Kedaulatan Data: Hanya ringkasan angka agregat yang dikirim ke API; catatan detail tetap berada di perangkat lokal.
8 Protokol Keamanan, Google Drive Sync & Pemulihan Data
☁️ Google Drive OAuth 2.0 PKCE

Mendukung sinkronisasi awan mandiri langsung ke folder Google Drive pribadi pengguna. Menggunakan standar keamanan OAuth 2.0 dengan PKCE (Proof Key for Code Exchange), sehingga tidak ada token atau data yang melewati server perantara.

💾 Cadangan JSON Terenkripsi & CSV

Mendukung ekspor standar JSON v4 polos maupun proteksi kriptografi AES-GCM 256-bit + PBKDF2 (100.000 iterasi) via Web Crypto API. Berkas terenkripsi tidak dapat dibuka tanpa kata sandi yang sah. Ekspor CSV juga tersedia untuk Excel.

🛡️ Factory Reset (Penghapusan Total)

Tombol darurat Reset Pabrik menghapus seluruh catatan transaksi, konfigurasi dompet, target tabungan, anggaran, dan riwayat percakapan AI dari penyimpanan peramban secara permanen dan instan jika perangkat hendak dipindahtangankan.

9 Kesimpulan & Spesifikasi Rilis

Aplikasi Catatan Keuangan membuktikan bahwa aplikasi finansial modern dapat dibuat sepenuhnya privat, tanpa ketergantungan server runtime, berdaya guna tinggi di pedalaman tanpa sinyal, dan diperkaya dengan kecerdasan buatan terdepan. Dengan 23 opsi tema estetis dan tata letak responsif, aplikasi ini siap menjadi pendamping finansial setia bagi siapa pun yang mendambakan kendali penuh atas uang pribadinya.
